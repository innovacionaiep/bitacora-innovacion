# linea-modulos-config

## Intent
Configurar por línea (no por fondo) qué tabs de proyecto y qué elementos de desarrollo técnico aplican, desde un tab Configuración → Líneas.

## Capabilities
- linea-modulos-config

## Rollback
Revertir flags en `Linea`, el tab de configuración, y el filtrado de tabs/listados. No borrar filas de negocio. Las columnas de `Fondo.conveniosEnabled` / `escalamientoEnabled` permanecen (deprecadas).

## Status
Applied (implementation in tree).
